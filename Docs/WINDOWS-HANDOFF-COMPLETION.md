## 实现范围

- 远征：双敌支线安全出生点、断供碎石避让、阶段与种子诊断；生成错误优先于机制建议与入场成功通知，详细诊断可展开并按实际文本高度滚动。普通前两房清场开门，守印与其他专属空间目标仍须完成。
- 操作与字体：浮动摇杆、依据能量/冷却/治疗资源/满血/目标可达性判断的技能高亮、PC 单框完整图标、药剂数量角标、移除快捷栏标题；祝福双击确认与滚动/前台输入取消兼容。桌面字号设置作用于文字与按钮样式，字号变化参与样式缓存键，避免只改变设置文案。
- 挂件：机制独立于装备，换装沿用；同机制拒绝重复购买；升级、变体、升华和方案挂载记录。旧机制装备继续保留属性、部位强化与原有投资入口。
- 成长：职业目标自动安排，达成后持久回执确保奖励一次并自动推进；每个目标奖励 50 金币与 1 星烬碎片。卡片定位职业练习、挂件服务或传送门；手动第二方案完成后打开方案 B 检查。
- 收藏：装备与时装共用图卡、图标与预览入口，装备预览保留其他实际装备及时装，支持穿戴；史诗/传说翅膀扩大翼展并增加层次。待领取红点表示物品存在，满包仍保留。
- 副本：入口显示目标与奖励身份；成功结算减字、图标奖励卡、直接进入下一阶。下一阶先持久结算宝箱/奖励，保存失败留在结果页；成功页去掉菜单/存档按钮，失败恢复入口仍在。
- 元素师：大招预览、蓄势、阶段命中和爆发共用范围常量，尾声保留原伤害事件预算。基础阶段半径 8 米、最终爆发 9.5 米，再乘技能阶级范围系数；未改变伤害系数与掉落概率。
- 城镇：NPC 移至中央可达空地；M 键打开旅行地图，各镇设旅行符文和到达点，旅行逐站进行且保留解锁要求。赤岩补给委托与星望星图增加持续内容。
- 场景：营地低箱、石台有实体碰撞与导航障碍，支持跳上、站稳、跳下；地面敌人绕行，近战与远程保留高差/视线规则。

## 挂件数据与迁移

| 原数据或入口 | 处理方式 |
| --- | --- |
| 库存、待领取、回收中的同机制旧装备 | 合并到一个独立挂件；原装备及属性原样保留 |
| 旧版本已穿戴机制 | 首次迁移保持挂载及所选变体 |
| 重复已存挂件 | 合并最高等级、升阶、品质、解锁和挂载投入 |
| 新机制装备掉落 | 装备仍入原领取流程，同时解锁对应挂件 |
| 首通自选、12 碎片兑换 | 直接授予挂件；满包不阻塞；已有同机制拒绝重复 |
| 旧方案与非当前职业方案 | 补充独立挂载/变体记录；仍保留装备、技能与方案投入 |
| 旧目标装备丢失 | 按原机制或来源身份定位挂件，继续对应成长操作 |
| 切换职业 | 按职业筛选机制、方案和成长奖励回执 |

挂件最高 5 阶，每阶消耗 6 星烬碎片，依次要求角色 6/11/16/21/26 级。
碎片沿用副本与原有奖励来源，也可通过星纹兑换与赤岩委托取得。
每阶攻击 +1.5%、生命 +2%、机制核心强度 +8%；第 3 阶拓展范围或伙伴生命，
第 5 阶额外核心强度 +20%。首次变体学习 4 碎片，之后免费切换。
通关第 5 阶并消耗 24 碎片可升华史诗挂件，传说机制额外强度 +15%。
升级、挂载、变体与升华使用候选存档提交，失败不扣道具，且不恢复生命、能量或清空冷却。
迁移是内存读取归一化，成功持久操作时才写入；不批量改写其他角色文件。
首次成功保存使用版本 4 文件封套；旧版本客户端会拒绝读取和覆盖，避免丢失挂件投入与自动奖励回执。
首通、兑换与挂件升华继续发布提交后的奖励提示，以挂件身份、品质及真实碎片消耗展示。
