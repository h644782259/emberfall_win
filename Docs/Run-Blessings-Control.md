# 本局祝福、首领打断与控制恢复

## 祝福池（14 项）

祝福选择仅保留在回廊远征：首房目标完成后、休憩室各一次。沉星遗迹、守望林庭、烬河突围、蚀星斗场不再弹出波间/阶段祝福选择，自动衔接下一波，原有阶段回血保留。首章入场战术不受影响。

回廊远征每次三选一，同一项最多 1 层，同一局不重复选取同一项。固定种子、职业、已学技能与选择路径得到固定卡牌顺序；每次至少两项立刻可用。祝福仅存在于 `RunChoices`，不加入角色存档、永久属性或装备。

保留 6 项：踏风余震、蓄星护佑、断势回流、猎印追风、破阵甘霖、星烬契约。

新增 8 项：
- 鹰眼星辉：暴击率 +10 个百分点，祝福加成最多到 80%；不会降低原本更高的暴击率
- 致命锋芒：直伤暴击倍率 165% → 195%；持续伤害剥离真实暴击倍率，避免把暴击奖励重复乘入灼烧等伤害
- 战意昂扬：玩家攻击伤害 +15%，按攻击计算的技能同效
- 流转回响：新施放技能冷却 −15%，最低 1 秒；不修改已运行冷却，不随翻页/重试叠乘
- 疾风快手：普攻速度 +18%，不加速技能、持续伤害与伙伴攻击；玩家普攻间隔仍不低于 0.18 秒
- 星铁护体：额外减伤 10%
- 背水守护：当前生命 ≤35% 时额外减伤 15%；和星铁护体相加最多 25%，仍服从原有整体减伤下限
- 灵流奔涌：每秒额外恢复 2 能量，总计 6/秒；能量上限仍为 100

所有卡牌写明具体数值、层数上限与离开本局清除。成功进入新的副本/挑战才调用一次 `Player.ResetCooldownsForDungeonEntry()`；开关传送选择页、取消、失败与波间推进不调用。该 API 清空技能、普攻、闪现、被动与内置触发冷却，取消旧目标/蓄力并使旧场景延迟效果失效，但它本身不补充能量。

## 真正的预警打断

以下主命中可打断首领带青色打断符号的预警：剑卫「裂地冲击」、元素师「冰霜新星 / 陨星术」、游侠「震荡陷阱」、唤灵师「灵能冲击」。技能说明与首领预警文字也标明此规则。普通攻击、持续伤害、伙伴攻击和治疗不能靠高频小眩晕无限取消首领攻击。

- 首领：打断后硬直 0.45 秒，5 秒内不能再次打断；危险外边界始终橙红，独立计时弧表示蓄力进度；恢复期不显示青色打断符号，恢复结束重新显示
- 精英：明确打断硬直 0.65 秒，打断恢复 2.5 秒；普通硬控缩短至 55%，单次最多 0.8 秒，之后至少 1.1 秒恢复
- 普通：明确打断硬直 0.9 秒，打断恢复 1.4 秒；普通硬控单次最多 1.5 秒，之后至少 0.45 秒恢复

每个目标记录每次控制技能的首次命中。一次施法不能多段重复打断，也不能先命中空闲/霸体敌人，再借同一个滞留区域取消下一次预警。打断只能发生在风起阶段；已发射的弹丸不会凭空消失，冲锋开始后不能回溯为“打断蓄力”。

接受打断时，取消风起、冲锋、连招间隔、剩余连招、侧移、待发协程和 Invoke，移除预警并放弃待确认完美闪避奖励。已取消的攻击不能由迟到的解析入口重新释放。

## 击退与画面边界

普通/精英/首领击退强度分别为原始强度的 100% / 55% / 12%，速度上限分别为 11 / 6 / 1.8，连续冲量有 0.12 / 0.35 / 1 秒恢复。合并冲量再次限幅，移动走 `WorldTraversal`，不能把敌人推穿场景边界或障碍。首领已开始冲锋时不接受侧向击退。

牵引同样走统一目标预算：普通/精英/首领分别按 100% / 55% / 12% 衰减，每目标每帧合计不超过 5 / 2.5 / 0.6 米每秒对应位移；时间步长预算最高 0.1 秒，重叠多个区域不会绕过限额。首领冲锋中不接受牵引。

高频命中硬直有独立恢复间隔，不能靠持续火花冻结移动。冻结、击倒和浮空表现只使用实际获准的控制时间；首领免疫普通硬冻结/浮空，但仍可以被明确的控制技能打断带青色打断符号的预警，也保留霜痕等组合条件。

玩家大范围效果降低边缘透明度与宽度，不叠加不透明地板。敌人预警使用独立、薄线、较高渲染优先级的边界材质，覆盖在地面粒子上；青色/红色同时配合「可打断 / 霸体恢复」文字，不仅依赖颜色。材质放在 Resources 以保证玩家构建包含它。现有移动端效果数量上限保留。

## 可选竞技场首领偏好

`ConfigureArenaBoss(0/1/2/3)` 只控制招式偏好，0 完整保留普通策略；1 主动接近震地范围，2 优先扇形弹幕，3 在可达距离内优先冲锋。仍保留距离、路径和重复招式检查，不改变血量/伤害/预警时长；偏好不合法或路径不通就退回原策略，后续连招继续使用原安全规则。

- `RunChoicesTests`：种子确定性、14 项卡池、两项可用、重复选择/波次、层数与退出重置
- `RunCombatRulesTests`：增益数值/边界、真实暴击倍率剥离、所有职业技能的冷却下限与入场重置、能源不返还、三档控制恢复、每施法/每目标去重与非有限值拒绝

这些均是生产纯逻辑测试或源码接线检查，不代表 Unity Shader 编译、渲染、触屏/Windows 实战手感、真机音效或平台打包已经通过。
