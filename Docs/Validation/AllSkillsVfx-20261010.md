# 全职业技能特效优化 · 2026-10-10

四个职业共 40 个技能槽位。32 个主动技能及 4 个防御触发技能通过现有模型、投射物、命中、召唤和持续领域的共用渲染路径优化；4 个数值被动保持数值行为，无新增虚构施法。

## 视觉调整

- 剑卫：刀刃厚度、旋风上下层、大剑落点和地面碎岩的竖向爆发。
- 元素师：冰晶、火舌、分叉雷电的实体表面；持续火雷领域由线条补成真实网格，陨石保留暗部与发光裂隙。
- 游侠：箭体与飞行拖尾、陷阱蓄力实体及实际首击破裂、毒蔓竖向生长和尖刺。
- 召唤师：灵能核心、契约印记的竖向晶体、召唤落点分层花瓣及长矛投射物表面。
- 防御和恢复共用外壳的面部光照与流动高光；保留职业颜色。

所有新模型片段保留原有部件预算与特效租约；地面模型裁切遵循已有视线范围。投射物的可见子物体缩放与拖尾变化不改变模拟根节点、命中半径和飞行速度。

## 验证范围

- Unity 6000.6.4f1 / Metal：普通与低特效模式，64 次真实主动释放、8 次真实防御触发、8 次数值被动拒绝施法。504 张实际相机世界截图，排除 OnGUI；固定 60 Hz 游戏时间步长。使用隔离验证存档，不覆盖玩家存档。
- 此轮前后的 CombatProjectile.Update 字节完全一致；管理代码测试 491 个真实资源、工厂、模拟快照、拖尾和生命周期断言及 2 个负向对照通过。旧 SHA 基线已根据本轮之前已落地的玩法源码刷新，不用特效修改掩盖模拟变化。
- 特效池 4645 个所有权、重置、部件上限与复用断言及 3 个负向对照通过。
- Blender 特效 584457 个加载几何、裁切、解码和租约断言及 4 个负向对照通过。
- 持续领域 139 个覆盖变更连续性断言和旧算法负向对照通过。该管理测试验证 fallback 几何；新增真实网格由 Unity 相机渲染覆盖。
- 技能伤害预算 80 个断言通过。
- iOS 与 Windows 的 Unity API 编译分别验证。iOS Unity simulator 导出及 Xcode Release/iphonesimulator 构建成功，安装到 iPhone 16 Pro / iOS 26.5 并启动成功（PID 36163）。Windows 未运行实际播放器。

这些结果验证释放、渲染、预算与生命周期，不代表拥挤实战 FPS、真机性能或人工操作手感验收。当前全技能预览使用普通专精，Burn/Shatter 分支沿用共享实体路径，未声称每个专精变体都逐一完成渲染验收。
