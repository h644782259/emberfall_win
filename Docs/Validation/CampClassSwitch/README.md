# 营地自由切换职业

独立分支 `codex/camp-class-switch`，依赖配装方案页修复；不合并 main。本提交不修改宝箱经济。

## 数据与事务

- 同一角色四个固定、带版本的职业位置。当前 `GameProfile` 兼容字段是活跃职业的唯一权威；活跃位置仅保存初始化标记。离开职业时才生成休眠快照，避免事件回调更新后出现过期镜像。
- 初次访问按合法的十个技能位置保留配点、精通与快捷栏，不复制教程、路线专精或方案；再返回恢复该职业自己的配置、教程、目标和方案 A/B。
- 等级、经验、金币、真实装备 ID/基础/品质/变体/部位强化、地图与章节进度、首奖标记、回执和未开箱资格共享。跨职业机制知识保留，职业不匹配的机制不生效。出售与批量出售检查休眠职业方案引用。
- 保存先准备脱离当前对象的候选和玩家模型，持久化后替换玩家，再发布 Changed；旧控制器不会在通知中读取新职业。失败保留旧角色、伙伴、资源和奖励资格。
- 保存封装升级为 v2，首次切换先保存当前职业，再提交目标，使恢复备份也为 v2。测试使用不可变的旧版实际读写代码，确认不能加载或覆盖双份 v2 文件。

## 运行时与界面

安全营地独立入口；初选界面说明可在营地切换。草稿、方案确认、引用修复、出售确认或重铸预览未结束时禁止切换。冒险、试招、暂停、死亡、近敌/追击/预备攻击、弹体/持续技能及临时效果均阻止切换。

保持生命比例和当前能量，技能、闪避、被动、装备触发、核心及召唤师伙伴重生倒计时不刷新；休眠期间按会话时间推进。精通核心的部分消耗进度归各职业，首次访问不会复制。旧伙伴、施法回执、目标和输入退役；同帧重复提交拒绝。返回/取消/离开面板或角色重绑关闭失效预览，方案页重绑后折叠。
