# 副本奖励与界面调整 · 2026-10-08

## 行为

- Windows 删除可站立提示，并消除营地与旅行点的重复地面标签。iOS 原本未创建这些平台提示。
- 成长提示、营地工坊按钮、系统信息按垂直区域排布；展开历史记录时收起成长卡片。
- 副本及章节入口采用背包同源图标、品质边框和品质点。桌面悬浮查看品质范围及概率，移动端点击查看详情。
- 普通/限制治疗选项关闭，重试入口也不能重新启用限疗机制；使用背包药剂。
- 五类副本和三个章节节点分别保存解锁阶数。旧存档的一次性迁移保留已经解锁的访问权限，迁移后的通关只推进当前副本。

## 掉落表

阶数档位：1–4、5–9、10–19、20–39、40–100，对应 B=0…4。

| 来源 | 奖励 |
| --- | --- |
| 普通怪物 | 地面金币；装备概率 65%+5%×B；药剂概率 12%+3%×B |
| 首领 | 地面金币、装备、药剂；药剂数量 1+floor(B/2) |
| 沉星遗迹宝箱 | 稀有保底武器、稀有保底时装、3+B 碎片 |
| 守望林庭宝箱 | 稀有保底护甲、5+B 碎片 |
| 烬河突围宝箱 | 稀有保底饰品、5+B 碎片 |
| 蚀星斗场宝箱 | 史诗保底武器、3+B 碎片 |
| 回廊远征宝箱 | 护甲与饰品交替、4+B 碎片 |

宝箱装备数量为 1+floor(B/2)，远征为 2+floor(B/2)。普通宝箱的史诗概率为 15%+5%×B，传说概率为 2%+2%×B；斗场传说概率为 10%+5%×B，其余为史诗。时装按稀有保底、同档史诗/传说概率发放，重复时装仍按已有规则转化。所有箱子额外提供金币和星纹。装备按开箱/掉落时角色等级生成。

章节也获得通关宝箱，三个节点分别使用林庭、烬河、斗场奖励类型；困难与英雄分别按奖励阶数+5、+10计算，最高100。原有章节首通及精通奖励保留。

## 保存

地面金币和药剂先进入存档中的待领取余额，拾取后原子转入背包；离场、死亡及重新加载保全未领取余额。箱子资格在通关时保存，装备在开箱成功保存后发放。保存格式7保存独立阶数与新奖励状态，冻结的旧宝箱继续使用原奖励。装备容量不足时保留宝箱资格，可整理后重试。
