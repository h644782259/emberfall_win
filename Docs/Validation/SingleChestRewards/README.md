# 单宝箱、实际到账资源展示与手动兑换

本分支在职业切换分支之上独立修改奖励，不改变通关基础奖励、首通核心、击杀奖励或装备数值。桌面与手机都只有一个“开启宝箱”；失败冻结后只有一个“继续开启”，不再选择箱型、部位或奖励结果。

新资格固定给予基础金币 G、1 星烬碎片、1 基础星纹；先抽品质（普通22%、稀有12%、史诗5%、传说1%、无外观60%），再在该品质的未拥有兵装／羽翼中随机补缺。该品质两件都有时各50%并按旧规则转化金币40/100/250/800、星纹1/2/4/8。拥有高品质不会阻止补低品质缺口。

新存档与此规则写入使用 envelope v3；职业状态档案仍保持自己的版本。旧已保存回执保持原语义，不重新抽签。旧已冻结失败抽签只继续原结果；旧尚未抽签的资格迁移为单宝箱，并仅这一次给予1.5G保护，后续新资格为G。显式 rulesRevision、rewardKind、materialKind 与实际 goldDelta/threadsDelta/materialsDelta 区分旧 choice=0/1/2，不重解释历史槽位。

抽签先冻结并持久化，再以一个候选存档原子提交资格消耗、资源增量、外观、回执与待展示标志。发奖写入失败可以从冻结存档重新启动后继续原抽签；如果最初冻结写入本身失败，只能保证当前进程重试相同，不能把磁盘写入失败说成已持久化。快照、另存档和职业切换保留冻结记录。所有资源均满时保留资格；冻结奖励因上限无法产生任何收益也不会消耗资格。

营地收藏页提供手动6星纹→1碎片，保留30星纹→未拥有传说外观。无自动兑换、星纹换金币或新货币。手动兑换用独立递增流水与回执，原请求重复调用不重复扣款；旧请求、换档、状态改变与资源上限由生产服务拒绝。按钮额外使用短暂连点门闩。兑换不覆盖宝箱回执。

视觉使用现有外观模型，加金币、碎片、星纹实际图形与到账数字；通关基础结算使用同一资源图形处理。保留已有揭示光效、音效、减少特效和跳过。页面绘制、动画跳过、返回和重复点击都不发奖。未增加夸赞式奖励文案。

经济影响明确：低阶每次基础3碎片变为开箱后4，约+33%；高阶7变8，约+14%。三次低阶通关并开箱共12碎片，相当于原四次基础通关；没有降低基础掉落来抵消。
