# 星烬纪元 / Emberfall

> **最新源码交付状态：** [2026-10-03 说明与验证边界](Docs/Release-2026-10-03.md)，覆盖已合并的 PR21–PR28。

> **0.4.0 源码：立体技能动画、十格触控、存读档、三城镇/三试炼与五房远征。** Windows/iOS已同步本轮功能；尚未发布新安装包或完成引擎画面/真机验收。见 [本轮说明与验证边界](Docs/Visual-Mobile-Release.md)。 后续数值与可靠性检查见 [第三轮检查](Docs/Combat-Review-3.md)。

Unity 3D 即时战斗 RPG 单机原型，当前使用 **Unity 6（6000.6.3f1）、Windows 64 位、Built-in Render Pipeline**。参考动作 RPG 的技能连招、闪避、副本和装备成长玩法，角色、名称与场景均为原创程序化内容。

现有发行包版本为 **0.3.1**，包含独立多存档、镜头旋转、跳跃与瞬移、实体障碍与生命药剂快捷栏。该历史发行包已完成 Windows 构建、打包和本机安装验证（153 个文件哈希一致、2 个原有存档保持不变），位于 `Builds/Release`。本开发分支的玩法、界面和部位强化仅更新源码，尚未生成新安装包；旧发行文件保持原样。

## 安装到其他电脑

Windows 64 位发行文件由打包工具生成到本地 `Builds/Release`；目录中的旧发行文件不会因修改源码自动更新：

- `Emberfall-Setup.exe`：运行安装器，选择安装位置，可创建桌面快捷方式。默认安装到当前用户的程序目录，不需要管理员权限。
- `Emberfall-Windows-x64.zip`：免安装版。完整解压后运行 `Emberfall.exe`，不要只复制 exe。

程序与存档完全分离。安装或更新游戏不会包含、删除或覆盖玩家存档。没有迁移存档的新电脑可以直接创建新角色。存档迁移步骤见下方「存档与换电脑」。

本版本安装器不写卸载注册表项。卸载时删除专用游戏安装文件夹和桌面快捷方式即可，独立存档仍会保留。

iPhone 源码、导出工具与文档单独维护在 [emberfall_ios 仓库](https://github.com/h644782259/emberfall_ios)，本 Windows 仓库不提供 iOS 导出工具。使用 Mac、Unity iOS Build Support 和 Xcode 安装到自己的 iPhone，支持选择 Personal Team；完整步骤见 [iOS 构建说明](https://github.com/h644782259/emberfall_ios/blob/main/Docs/iOS.md)。当前 Windows 环境没有 iOS 模块，未生成 Xcode/IPA，尚无真机通过结论。

## 开始试玩

1. 在 Unity Hub 安装 **Unity 6**，当前验证版本为 `6000.6.3f1`，并勾选 **Windows Build Support (Mono)**。开发机器上已检测到该编辑器与构建组件。
2. Unity Hub → Projects → Add → Add project from disk，选择克隆后的项目根目录（本机为 `E:\MyGame`）。不要创建新的 URP/HDRP 项目。
3. 等待首次导入和脚本编译完成。项目指南会自动打开，点击 **开始试玩**。也可以使用菜单 **Emberfall → 开始试玩 Play**。
4. 选择剑卫、元素师、游侠或唤灵师，然后点击「开始冒险」。若有存档，可选择「继续冒险」，再从列表选择角色。

`Assets/Scenes/Main.unity` 是启动场景；进入 Play 后会自动创建世界、角色、摄像机和界面，所以编辑状态的场景为空属于预期行为。无需下载模型、贴图、商业插件或付费素材。

若编辑器安装在默认位置，可运行 `Tools/Open-Unity.ps1`。自定义位置使用：

```powershell
.\Tools\Open-Unity.ps1 -UnityPath 'D:\Unity\Editor\Unity.exe'
```

## 已实现玩法

### 交互与战斗

- 新增召唤师：灵狼近战、星灵远程、树灵范围重击；普通召唤物最多 4 只，树灵最多 1 只，具有生命与存在时间，可吸引敌人攻击。回春共鸣同时治疗角色与召唤物。
- 陨星、大地崩裂、星灵契约与终极技能等增加自动蓄力过程；显示进度，期间可以减速移动，Shift 瞬移、右键或 Esc 可取消。蓄力完成才扣资源和进入冷却，不需要一直按住技能键。
- 已学习主动技能可直接在 HUD 或技能配置区拖动：空槽移动、已占用槽交换；只改变当前十格配置，不改变技能自身的冷却。
- 副本装备先掉在地上，显示装备造型、名称与品质光柱；落地后靠近自动拾取，满包按售价转成金币。正常返回营地、回标题或退出游戏前会收取本次副本未拾取的装备。
- 命中增加短促火花、受击动作与撞击音，挥空保留挥击声。新增低音量背景乐、界面音与静音恢复反馈。
- 原野划分西侧林地、河流木桥、道路、东侧草地和遗迹庭院；副本包含入口长廊、东西侧廊、横厅与北部祭坛。河流阻挡步行，须走桥，或用瞬移跨越有安全落点的窄河段。
- 树干、岩石和石墙阻挡移动，跳跃和瞬移也不能穿过实体障碍；低矮石块同样阻挡。敌人与召唤伙伴会绕行。投射物可飞过河流，但会被实体障碍挡住。

- 紧凑图标 HUD，未学习技能呈现为空槽，技能名称、等级及说明移到悬浮提示；完整键盘/鼠标说明集中在「操作指南」。
- 自身范围、治疗、护盾、朝向攻击和锁定技能按键直接释放；需要选择地面落点的陨石、陷阱等技能进入范围预览，左键确认、右键或 Esc 取消，确认前不扣能量或冷却。
- 鼠标指向怪物身体可选中目标，移动时转身，攻击时自动面向目标；元素师普攻追踪选中敌人。
- 技能树包含前置和同级分支，旧档已有技能保留。冻结后的减速、持续中毒（最多 3 层）、击倒、眩晕、聚怪和单目标锁定各有独立机制。
- 普通怪默认中立，受到攻击才反击；副本精英与首领主动攻击，首领具有控制抗性。
- 背包按部位筛选，按综合属性（攻击×5＋防御×3＋生命×0.2）、等级或品质降序排列；强于同部位当前装备时显示绿色「↑ 提升」，等级不足会变暗并显示等级锁，不能装备。未穿戴装备可直接出售。
- 强化永久绑定武器、护甲、饰品三个部位；换装自动套用该部位等级，按新装备自身基础属性计算，无需手动转移。替换或出售装备不丢部位强化。旧档每个部位继承背包、待领取和回收箱中最高的历史强化等级，不叠加，原装备基础数值保留；曾强化的旧装备自动锁定保护。
- 四职业具有各自模型、武器与动作，技能包含实体光束、晶片、冲击波、下落巨剑和召唤伙伴。

- **四种职业**：剑卫近战范围斩击，元素师远程法术与冰霜控制，游侠快速射击与群体箭雨，召唤师以契约伙伴、荆棘和引力印记协战。
- **即时战斗**：鼠标瞄准、连发普通攻击、闪避无敌、技能冷却、投射物、范围伤害、击退与眩晕。
- **原野探索**：风语原野、营地、遗迹传送门。史莱姆跳扑并附加减速，哥布林绕侧突袭，魔灵远距游走与双弹，守卫正面石甲减伤但重击蓄力时露出破绽。
- **副本**：沉星遗迹三波挑战，最终 Boss 星蚀巨像有范围重击、冲锋与扇形弹幕；攻击有红色预警。波间回复生命，通关给予额外经验和金币，后续挑战阶数上升。
- **主动与被动**：每职业 10 个基础技能，其中 8 主动、2 被动。技能区分输出、控制、位移、增益、防御和治疗；被动学习后自动生效，不能放入主动快捷栏。
- **原技能进阶**：新角色在 1 级自动学习并配置首个主动技能一阶；终身技能点总预算为 `max(1, level - 1)`，1 级的 1 点已投入，升至 2 级不额外给点，此后每升一级增加 1 点。技能按 1 / 4 / 6 / 10 / 13 / 20 / 30 级分层开放，其中 4、6、13 级各有两个分支节点，初次学习须点亮连线前置。学习和升阶各消耗 1 点。首个主动技能二阶/三阶仍需 10/20 级；其余技能强化需基础解锁等级 +8，觉醒需 +18；继续使用同一个技能，不新增技能格。进阶改变数值、范围、段数、特效或控制/防护机制，技能界面可预览各阶段。
- **战斗取舍**：冷却与消耗按职业及技能效果配置，位移、召唤、持续领域和爆发各有节奏；终极技能基础冷却分别为剑卫 42、元素师 45、游侠 40、召唤师 46 秒，进阶后缩短。能量上限 100，每秒恢复 4，普通攻击真实命中额外恢复 8；技能或召唤物攻击不回能。换键、拖放都不会重置技能冷却。
- **快捷栏**：固定十格、不翻页，桌面默认 Z/X/C/V/B、1/2/3/4/5。主动技能和生命药剂可分配、卸下、拖动或交换；桌面按键可以自定义，被占用的技能键自动交换，移动及功能键保留。移动端固定显示十个职业技能，含不可点击的被动状态。药剂数量为零时保留灰色图标，补货后可继续使用。
- **装备养成**：武器、护甲、饰品；普通、稀有、史诗、传说四种品质；装备有等级要求，可比较、替换、出售；三个部位分别强化至 +10，换装自动继承；Boss 必掉稀有及以上品质装备。
- **通关宝箱与时装**：每次副本通关后三选一开启宝箱，第1阶 60～100 金币，实际通关第5/10/20/40阶各提高25金币，最高160～200；每次开箱独立判定时装品质，普通 22%、稀有 12%、史诗 5%、传说 1%、无时装 60%。翅膀与武器外观各有独立穿戴位，所有等级可穿戴，按百分比提高生命/防御或攻击/暴击几率。重复时装转化金币；未开的宝箱和已收藏时装随角色存档保存，在行囊的「时装收藏」中管理。
- **补给与存档**：药水回复 50% 最大生命；背包商店购买；本地自动存档、备份恢复与存档校验；死亡不扣金币，保留已赚金币、装备、经验和技能；章节失败可按原条件从节点起点重试。
- **界面与音效**：中文职业选择、血量/经验/技能栏、小地图、背包、技能树、暂停、死亡与通关提示，以及程序化背景乐、界面反馈与战斗音效。

## 构建 Windows 游戏

Unity 菜单 **Emberfall → 构建 Windows 游戏 Build**。输出为 `Builds/Windows/Emberfall.exe`，分发时需要整个 `Builds/Windows` 文件夹。

或关闭该项目的编辑器后，在 PowerShell 运行：

```powershell
.\Tools\Build-Windows.ps1
# 编辑器在自定义目录时：
.\Tools\Build-Windows.ps1 -UnityPath 'D:\Unity\Editor\Unity.exe'
```

日志位于 `Logs/windows-build.log`。编辑器工具会设置窗口尺寸、输入轴对应的传统输入、构建场景、线性色彩和运行时需要的着色器保留列表。

构建后运行 `Tools/Package-Release.ps1`，生成安装器和完整免安装 ZIP。安装器源码位于 `Tools/Installer/Installer.cs`，可使用 `--verify-payload` 只校验内嵌发行文件，不执行安装。退出游戏后，可用 `Emberfall-Setup.exe --install-dir E:\EMBERFALL` 更新指定目录；安装失败会尝试恢复本次替换的文件，个人存档独立保留。命令行安装不创建快捷方式或自动启动游戏。

## 存档与换电脑

使用 `Application.persistentDataPath` 保存独立角色文件，Windows 存档文件夹通常为：

```text
%USERPROFILE%\AppData\LocalLow\EmberfallStudio\Emberfall
```

标题界面的「继续冒险」打开存档选择页，按最近保存时间排列职业、等级与日期。创建新角色会新建独立存档，保留已有角色；暂停菜单只有一个「保存」入口，确认覆盖具名当前角色后写回原槽位，也可从「读取存档」选择保存后切换、放弃未保存变更或取消。自动保存持续写回当前所选槽位，不因退出重复新建角色。

旧版 `emberfall-save.json` 原名保留；新存档使用 `emberfall-save-{32位编号}.json`，每份各有对应的 `.bak` 备份。坏档仍会显示但不可读取；若其备份可用，可从备份恢复，其他角色不受影响。不需要额外索引或 manifest。

游戏暂停菜单提供存档位置入口；Unity 菜单 **Emberfall → 打开存档文件夹 Saves** 也可定位。保存使用临时文件与原子替换。每份存档包含职业、等级、经验、金币、背包装备、技能进阶和自定义按键；旧三页配置字段仅为兼容保留，当前界面固定十格、不翻页，不依赖原电脑用户名、安装路径或机器标识。

1. 先保存并退出两端游戏，备份完整原存档目录，再保留全部 `emberfall-save*.json`、对应 `.bak`、可恢复 `.tmp` 和 `.delete-pending` 删除标记；不要单独搬运旧备份或丢弃中断标记。
2. 新电脑安装/解压游戏并运行一次，从暂停菜单或上述路径找到其存档目录，然后退出游戏。
3. 将这些文件复制到新电脑的该目录。先备份目标目录；不同编号的存档可以并存，相同文件名代表同一份存档或旧版存档，覆盖前确认要保留哪份。
4. 再次启动，点击「继续冒险」，选择要读取的角色。没有复制存档也可以点击「开始冒险」创建新的独立角色。

退出后再次进入会回到营地，不保存未完成副本的波次。升级版读取早期三技能存档时会保留角色与装备；不符合新进阶等级门槛的阶段会返还技能点，并明确提示。覆盖保存失败或坏档读取失败不会切换当前已载入的角色。
